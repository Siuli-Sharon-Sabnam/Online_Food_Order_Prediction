# 🍽️ Online Food Order Prediction

This project aims to predict customer behavior in online food ordering using machine learning techniques. By analyzing various factors influencing online food orders, the model provides insights that can help businesses optimize their marketing strategies and improve customer retention.

---

## 📌 Project Overview

- **Objective**: Predict whether a customer will place an online food order based on demographic and behavioral features.
- **Dataset**: Includes features such as age, gender, marital status, occupation, income, education, family size, location, and feedback.
- **Approach**:
  - Data preprocessing and cleaning
  - Exploratory Data Analysis (EDA)
  - Model training using Random Forest Classifier
  - Model evaluation

---

## 🧠 Key Features

- Data preprocessing and encoding
- EDA with key visualizations
- 85.8% model accuracy using Random Forest
- Key insights on customer ordering behavior
